Used as the project's default GUI font (project.godot [gui] theme/custom_font)
to render Korean UI text in the HTML5/web export -- the engine's built-in
default font has no CJK glyph coverage and falls back to tofu boxes on web,
where OS font fallback isn't available (see 2026-08-02 web export smoke test).
