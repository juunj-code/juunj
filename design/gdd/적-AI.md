## Overview

적 AI 시스템은 전투 중 각 적 유닛의 행동(타겟 선택·액션 선택)을 결정하는 Core 레이어 시스템이다. #11 적 데이터의 스탯·스킬을 입력으로 받아, #6 전투 공식이 정의한 턴 순서 내에서 적이 "무엇을 할지"를 결정한다. MVP 설계 원칙: **단순하고 읽히는 AI** — 플레이어가 1~2턴 관찰 후 "이 적은 빠른 녀석부터 공격한다"는 패턴을 파악할 수 있어야 한다. 무작위성은 최소화하고, 역할(속도형·탱커형·보스)에 따른 일관된 행동 규칙을 우선한다. 복잡한 상태머신·MCTS·학습 AI는 YAGNI — Vertical Slice 이후 플레이테스트에서 단순 AI가 충분하지 않을 때 확장한다.

## Player Fantasy

"이 적 패턴 읽었다." — 그리고 그 읽음이 실제 전략적 우위로 이어지는 경험.

- 속도형 적은 항상 HP가 낮은 동료를 먼저 노린다. 플레이어는 빠른 적이 등장하면 저HP 동료를 앞에 두지 않는 판단을 내린다.
- 보스는 3턴마다 강 스킬을 쓴다. 플레이어는 "2턴 남았다, 힐할 타이밍"을 계산한다.
- "이 적이 왜 저걸 공격했지?"가 없는 전투. 이해 가능한 AI가 전략적 선택을 의미 있게 만든다.

## Detailed Rules

### AI 행동 순서 (매 적 턴)

```
1. 액션 선택: SP >= skill.cost_sp → 스킬 / 아니면 → 기본 공격
2. 타겟 선택: 아래 타겟팅 규칙 적용
3. #6 전투 공식으로 데미지 계산 → HP 적용
```

### 액션 선택 규칙

| 조건 | 액션 |
|------|------|
| `current_sp >= skill.cost_sp` | 스킬 사용 (항상 스킬 우선) |
| `current_sp < skill.cost_sp` | 기본 공격 |

MVP 단순화: 적은 스킬을 쓸 수 있으면 항상 쓴다. 전략적 보류 없음 — 보스 포함. 결과적으로 SP 시스템이 "적 스킬 주기"를 자연스럽게 결정한다 (cost_sp=3 → 3턴마다 강 스킬).

### 타겟팅 규칙

**일반 적 (is_boss = false):**

| 우선순위 | 규칙 | 이유 |
|----------|------|------|
| 1순위 | HP가 가장 낮은 동료 | 집중 제거 = 읽히는 위협. 스피드형 적이 약한 동료를 노린다는 직관과 일치 |
| 타이브레이크 | 파티 인덱스 낮은 쪽 (슬롯 0 우선) | 결정론적 — 동일 HP 시 무작위 없음 |

**보스 (is_boss = true):**

| 우선순위 | 규칙 | 이유 |
|----------|------|------|
| 1순위 | ATK가 가장 높은 동료 | 딜러를 먼저 제거하는 보스 = 더 위협적이고 "영리해 보이는" 패턴 |
| 타이브레이크 | HP가 낮은 쪽 | 동 ATK 시 약한 쪽 먼저 |

### 타겟 분산 규칙 (Edge Case #11 GDD 계승)

3마리 일반 적이 동일 타겟에 집중하면 한 턴에 최대 39 데미지(13×3) — 60HP 동료 즉사 위험. 이를 방지:

```
같은 턴, 이미 동일 타겟을 공격한 적이 있으면:
  → 차순위 타겟(다음으로 HP 낮은 동료)으로 강제 분산
단, 생존 동료가 1명이면 분산 없이 집중 허용
```

# ponytail: 단순 분산 룰. 실제 최적 타겟팅(예상 데미지 기반)은 플레이테스트에서 필요 시 추가.

### Core Rules

1. **결정론적 AI**: 동일 전투 상태에서 항상 동일한 결정. 무작위 없음 — 패턴 파악이 가능해야 한다.
2. **읽히는 역할**: 속도형 적은 저HP 타겟, 보스는 고ATK 타겟. 외형·스탯 차이가 행동 차이로 이어진다.
3. **이 시스템은 데미지를 계산하지 않음**: 타겟·액션만 결정. 데미지는 #6 전투 공식 호출.
4. **상태이상 무시 (MVP)**: 버프·디버프 상태를 타겟 계산에 반영하지 않는다. #12 상태이상 GDD에서 AI 행동 수정 여부 결정.

## Formulas

이 시스템은 수치 공식이 아닌 **우선순위 규칙**을 소유한다.

**타겟 점수 (일반 적):**
```
target_score = -current_hp   # 낮을수록 우선 (HP 오름차순 정렬 = 내림차순 점수)
tie_break    = party_index   # 낮을수록 우선
```

**타겟 점수 (보스):**
```
target_score_primary   = -base_atk     # 높을수록 우선 (ATK 내림차순)
target_score_secondary = -current_hp   # 동 ATK 시 HP 낮은 쪽
```

**스킬 사용 임계값:**
```
use_skill = (current_sp >= skill.cost_sp)   # bool, 단순 비교
```

## Edge Cases

- **생존 동료가 1명**: 타겟 분산 규칙 비적용, 모든 적이 해당 동료 집중 가능. 마지막 동료이므로 분산 의미 없음.

- **모든 동료 HP 동일 + 파티 인덱스 동일**: 발생 불가 (인덱스는 항상 고유). 타이브레이크 완전 결정론 보장.

- **보스: 모든 동료 ATK 동일**: HP가 낮은 쪽 선택. HP도 동일하면 파티 인덱스 낮은 쪽.

- **상태이상으로 동료 ATK·HP 수정**: MVP에서 AI는 base_atk·base_hp만 본다(런타임 수정값 무시). 복잡도 대비 효과 미검증 — 필요 시 Vertical Slice에서 `current_atk` 기반으로 전환.

- **적이 행동할 때 타겟 동료가 이미 처치된 경우**: 처치 판정은 #6 공식의 HP 차감 후 즉시 발생. AI는 살아있는 동료 목록만 받아 타겟 결정 — 이미 처치된 동료는 후보에 없다. #1 턴제 전투가 살아있는 동료 목록을 최신 상태로 넘겨야 함.

## Tuning Knobs

| 조정값 | 현재 설정 | 안전 범위 | 너무 낮을 때 | 너무 높을 때 |
|--------|-----------|-----------|-------------|-------------|
| 일반 적 타겟 기준 | 최저 HP | — | 무작위처럼 느껴짐 | 단조롭고 예측이 너무 쉬움 |
| 보스 타겟 기준 | 최고 ATK | — | 보스가 덜 위협적 | "가장 강한 동료부터 죽여" 패턴이 너무 명확해 파티 구성 자유도 감소 |
| 타겟 분산 강제 | 동일 턴 동일 타겟 시 분산 | — | 즉사 위험 | 분산 없음 → 집중 공격 전략 불가 (전략 깊이 감소) |

## Visual/Audio Requirements

이 시스템은 시각/오디오 자산을 소유하지 않는다. AI가 결정한 액션·타겟을 #1 턴제 전투에 전달하면, 전투 시스템이 애니메이션과 SFX를 처리한다.

## UI Requirements

이 시스템은 UI를 소유하지 않는다. 적의 행동 의도(타겟 표시 화살표 등)는 `#20 UI/HUD` 소유.

## Acceptance Criteria

1. (타겟팅 – 일반 적) GIVEN 동료 A(HP=60), B(HP=30), C(HP=80)이 생존한 상태에서 WHEN 일반 적이 타겟을 결정하면 THEN B(HP 최저)를 선택한다.

2. (타겟팅 – 타이브레이크) GIVEN 동료 A(HP=50, 슬롯0), B(HP=50, 슬롯1)이 생존한 상태에서 WHEN 일반 적이 타겟을 결정하면 THEN A(슬롯 인덱스 0)를 선택한다.

3. (타겟팅 – 보스) GIVEN 동료 A(ATK=28), B(ATK=14), C(ATK=18)이 생존한 상태에서 WHEN 보스가 타겟을 결정하면 THEN A(ATK 최고)를 선택한다.

4. (액션 선택 – 스킬) GIVEN 적의 current_sp=3이고 skill.cost_sp=3인 상태에서 WHEN 액션을 결정하면 THEN 스킬을 선택한다.

5. (액션 선택 – 기본 공격) GIVEN 적의 current_sp=2이고 skill.cost_sp=3인 상태에서 WHEN 액션을 결정하면 THEN 기본 공격을 선택한다.

6. (분산 규칙) GIVEN 일반 적 A·B·C가 있고 동료 X(HP=20)·Y(HP=50)가 생존 중이며, 같은 턴 적 A가 이미 X를 타겟으로 결정한 상태에서 WHEN 적 B가 타겟을 결정하면 THEN Y(차순위)를 선택한다.

7. (분산 예외 – 생존 1명) GIVEN 생존 동료가 X 1명뿐인 상태에서 WHEN 적 A·B·C가 모두 타겟을 결정하면 THEN 세 적 모두 X를 선택한다 (분산 미적용).

8. (결정론) GIVEN 동일한 전투 상태(동료 HP·ATK·슬롯, 적 SP 동일)에서 WHEN AI를 두 번 실행하면 THEN 두 결과가 완전히 동일하다 (무작위 없음).

9. (처치된 동료 제외) GIVEN 동료 A(HP=0, 처치), B(HP=40)인 상태에서 WHEN 일반 적이 타겟을 결정하면 THEN B를 선택하고 A를 타겟으로 삼지 않는다.
